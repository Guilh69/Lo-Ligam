## Points à signaler hors texte (pas touchés : logique ou code)

- `LegendaLocutors.svelte` : la classe haute s'écrit `'20 +'` dans le code ; en lecture de droite à gauche le signe « + » peut passer devant (« +20 »). Contourner par `dir="ltr"` sur ce `<span>` ou par un marqueur de sens.
- Flèches de texte `→` dans `VotzAtlas.svelte` (« Voix suivante : … → ») et `VotzFicha.svelte` (« … sur la carte → ») : elles pointent vers la droite, donc vers l'arrière en arabe. À retourner (comme déjà fait pour les icônes « suivant »).
- `RailJaces.svelte` : `kmTèxt` met une virgule décimale sauf en anglais ; l'arabe utilise donc la virgule latine (« 1,5 km »). Lisible, laissé tel quel (chiffres occidentaux, unités latines « km », « m »).
- `RailJaces.svelte` : pour toute langue autre que l'occitan, les pastilles des dialectes affichent les noms français (« gascon », « languedocien »…), non les noms occitans. Même comportement qu'en es/en/ca ; c'est la logique de choix des noms, non modifiée.
- `OfficialitatCarousel.svelte` : le défilement horizontal et les touches ← → ne sont pas inversés en droite à gauche ; à vérifier à l'écran.
- Non vérifié visuellement : la largeur des libellés arabes dans les boutons étroits du rail (aucune capture faite, le panneau Browser n'étant pas accessible depuis ce passage).
