# Les cours en visio de l'A1 : le plan par défaut

> Ouvert le 2026-11-01 à partir du plan dicté par Romain (chantier 20, cahier §11).
> Règle de Romain : « Ils doivent être en cohérence avec le module autonome. En visio, pas bloqué et adaptable à la carte, mais c'est le plan par défaut. »

## 1. Le format d'un cours (une heure, quatre temps)

| Temps | Ce qu'on fait | Lien avec le parcours autonome |
|---|---|---|
| 1. Culture et contexte | quelques idées fortes sur la langue, le pays, les gens | l'encart culture de l'unité, la carte de titre |
| 2. On écoute | une chanson, avec les paroles | l'étape « écoute » des modules, les liens vers Òbras (musique) |
| 3. On lit | un texte d'auteur, court | l'étape « observe » |
| 4. Les mots | les formules et les formes du jour, à l'oral | les mots et formes de l'unité, qui entrent dans le carnet de révision |

Ce plan est celui qu'on suit **par défaut**. En séance, Romain l'adapte à la personne : rien n'est bloqué.

**Un cours par unité** (Romain, 2026-11-01) : en A1, neuf cours par défaut. Le cours 0 accompagne le module 0, puis un cours par unité, de 1 à 8. Le temps 4 reprend les mots et formes de l'unité ; culture, chanson et texte sont le plus de la visio et nourrissent l'encart culture de l'unité.

## 2. Cours 0 · *Benvengut dins lo mond occitan* (version de Romain du 2026-11-01)

**1. Culture et contexte : qu'est-ce que l'occitan ?**
- une langue latine ;
- une langue dialectale ;
- minorisée ;
- sans statut officiel en France ;
- parlée dans la moitié sud de la France, dans le Val d'Aran et dans les vallées occitanes d'Italie ;
- entre 600 000 et plusieurs millions d'occitanophones, selon le niveau ;
- une langue de littérature, qui a connu le fameux mouvement des troubadours ;
- la langue d'où vient l'accent méridional, si chantant ;
- une langue fragile, mais portée par des passionnés.

**2. On écoute** : *Amor d'Aussau*.

**3. On lit** : un poème de Max Roqueta.

**4. Les premiers mots** : *Adieu* · *Cossí vas ?* · *Va plan, e tu ?* · *Vau plan, mercés* · *Al còp que ven* · *A lèu*.

Vérification lo Congrès du 2026-11-01 (`verificar-oc.mjs`) : *benvengut, dins, mond, occitan, adieu, cossí, vas, plan, mercés, còp, lèu* confirmés dans le Basic (variété languedocienne) ; *va, vau* (verbe *anar*) et *ven* (verbe *venir*) confirmés comme formes conjuguées par vèrb'Òc.

Versions précédentes dictées le même jour (pour mémoire) : un cours 0 sur « la France multiculturelle » (langues régionales, peuple, construction nationale ; *Se canta* ; la Déclaration des droits de l'homme en occitan ; se décrire) et un second sur le statut de l'occitan (patrimoine, Val d'Aran, Italie, loi Molac ; Cocanha ; un extrait de *Mirèio*). La description physique de la première version relève, dans la carte A1, de l'unité 7.3 (couleurs et tailles) et de l'unité 3 (famille).

## 3. Points relevés à la vérification (à trancher par Romain)

1. ✅ *Tranché le 2026-11-01 : les formules de Romain font foi ; module 1.1 aligné (Vau plan, mercés ; Al còp que ven ; mercés en 1.1 et 1.2).* **Cohérence des mots avec le module 1.1** : le module autonome dit *Va plan, mercé* (ça va bien, merci) ; le cours dit *Vau plan, mercés* (je vais bien, merci) et ajoute *Al còp que ven*. Les deux formes sont justes ; il faut choisir lesquelles les deux supports partagent.
2. **Les droits** : Max Roqueta est mort en 2005, ses textes sont protégés ; en visio, lire un court extrait à l'élève reste un usage de cours, mais le parcours autonome ne pourra pas le reproduire sans accord. Pour les chansons, on renvoie à l'écoute sur une plateforme, sans copier l'enregistrement ni les paroles sur le site (décision du chantier 21). *Mirèio* (Mistral, 1859) est libre de droits.
3. **« Une langue dialectale »** : la formule peut être entendue comme « un dialecte », l'idée reçue du patois. Variante possible : « une langue riche de six grands dialectes ».
4. **Les chiffres** : 600 000 locuteurs vient de l'enquête de l'OPLO (2020, déjà sourcée sur le site) ; le haut de la fourchette (« plusieurs millions ») est à rattacher à une source avant d'être affiché sur le site.
5. **La page `/apren/visio`** annonce encore « une heure en cinq temps » (semaine ou lecture, prononciation et mots, grammaire, écriture, chanson) : à aligner sur les quatre temps une fois le format confirmé.
