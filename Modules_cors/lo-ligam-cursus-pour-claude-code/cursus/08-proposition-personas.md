## 2. Ce sur quoi tout le monde converge (à faire, sans débat)

**C1 · Audio d'abord.** 10/10 le demandent ; 4 en font une condition d'usage. Aucun module ne doit être publié sans dialogue, chunks et corrigés enregistrés par une voix humaine. Louis et Sylvain refusent la synthèse Votz ; Josette et Lina ne lisent pas l'API.

**C2 · Micro-sessions.** Théo, Lina, Josette, Inès, Marc : le module de 45-60 min est un mur. Découper chaque module en **4-6 sessions de 10-15 min** (Rappel+Input / Observa / 3a / 3b+Fluiditat / Tâche / Bilan), chacune avec un « terminé ». Le gabarit ne change pas, il se **paginera**.

**C3 · Corriger la langue avant d'écrire la suite** (Sylvain, Fabre) :
- *après* → **aprés** (participe de *aprene*, 3 occurrences en 44.1) ;
- *cedèsse* → **cediguèsse** ; *sapièsse/sapièsson* → **saupèsse/saupèsson** ; *poscan* → **pòscan** ;
- *partís, dormisson* (11.1) → **part, dòrmon** — et **fixer la liste fermée des verbes en *-ir* inchoatifs / non inchoatifs** dans le cadre §3 ;
- *un pauc* [pawk] ; *lo president novèl* → *lo nòu president* ; *cadun sorgada* → *caduna* ; *sorgar* → *documentar/referenciar* ; *lo mond* : accord singulier tenu partout ;
- *agla* est féminin chez Alibèrt : lever le ⚠️.

**C4 · Tâche finale toujours en version privée.** Josette, Marc, Théo, Lina : « poste en commentaire / envoie à ton binôme » suppose une communauté qui n'existe pas encore. Chaque tâche propose **deux voies** : privée (enregistre pour toi / carnet) et communautaire (commentaire Lo Ligam, binôme attribué).

**C5 · Jargon hors des modules.** « input flood, structured input, dictogloss, 4/3/2, J+2 » restent dans le cadre (doc de travail) ; dans les modules apprenants, titres en langage courant (*Écoute · Observe · Entraîne-toi · Va plus vite · À toi*).

**C6 · Les natifs comme voix et relecteurs** (Louis, Fabre, Sylvain, Bernard) : chaque dialogue enregistré **deux fois** (voix modèle + voix native locale) dès l'unité 0 ; brique « *Lo conselh dels vièlhs* » dans le gabarit (un natif relit, formulaire « chez nous on dit… ») ; Laura de Sant Africa parle rouergat ou déménage.

## 3. Les contradictions et comment je propose de les arbitrer

| Tension | Positions | Arbitrage proposé |
|---|---|---|
| **Contenus « luttes »** (Larzac, 1907, Molac, pétition) | Bernard, Marc : trop, ça exclut · Inès, Louis, Lina : c'est ce qui fait vivre la langue | **Ne rien retirer, équilibrer** : pour chaque encart « lutte », un encart « bâtisseurs / métiers / terroir » (vigne, bastides, Félibrige, cuisine, chasse) ; **deux sujets au choix** dans les tâches finales concernées (29.5, 31.5, 33.5, 37.x). Louis rappelle que le Larzac n'est pas de la politique pour ceux qui l'ont vécu : on le garde, on le raconte par les gens, pas par la cause. |
| **Le tableau « forme mise en avant / variante »** | Louis : vexant · Fabre : conventionnel mais reconduit une hiérarchie · Núria, Bernard : honnête | Renommer : **« Forme d'apprentissage » / « Formes également en usage »**, avec **le nom du pays** à côté de chaque forme (*nuòch* — Roergue, Albigés ; *nautres* — Roergue…). Le principe reste ; la présentation cesse de dire « vrai / cousin ». |
| **Francitan** | Fabre, Louis : « residuala » et « exclu » = mépris · le cursus veut éviter les calques | Réécrire §2 et Cultura 44.1 : le francitan des balcons **est de l'occitan** et un point d'appui ; ce que le cursus traite, ce sont les **calques du français chez l'apprenant**, jamais la parole des natifs. Renommer la rubrique « Francitan / francismes » en **« Calcs a evitar »**. |
| **Variation trop tardive (B1 28)** | Fabre, Louis, Josette : dès le début · le cadre voulait un modèle stable en A1 | Garder **un** modèle de production en A1, mais **exposer** dès l'unité 0 : encart « *Los que parlan* » (30 s de 3 natifs, zones différentes) dans chaque unité A1-A2, et **carte « ta zone dit… »** dès 1.3. La production reste stable ; l'oreille est ouverte tout de suite. |
| **Tutoiement** | Josette : gênée · ton Lo Ligam : tu | Garder *tu* (cohérence de marque), mais **bouton vos** dans l'interface si la techno le permet ; sinon, tutoiement chaleureux et jamais injonctif. |
| **Unité 0 phonologie** | Sylvain : indispensable · Théo, Josette, Lina : mur | Garder le contenu, **fondre** : un contraste sonore par module d'A1 (le jour de *bon ser* → *è/e*), avec audio ; unité 0 devient un module d'accueil de 15 min « Tu l'as déjà entendu » (écoute d'un natif + texte à côté) + un test d'oreille optionnel. |
| **Volume et parcours** | Marc : « 80 h pour commander un cassoulet » · Núria : trop lent pour une romanophone · Sylvain : plutôt 6 mois pour A1 | (a) Afficher des **durées réalistes** (A1 = 4-6 mois à 3 modules/sem.) ; (b) **test de positionnement** + parcours accéléré romanophone (validation par mission directe, prétérit/subjonctif en réception dès A2) ; (c) un **parcours « Pro 10 h »** (accueil client, étiquette, marché) — utile pour les labels *en òc*, mais **phase ultérieure** : hors périmètre de la phase 1 du projet. |

## 4. Ce que je propose de faire (priorisé)

### P0 — avant d'écrire un module de plus
1. Corriger les fautes listées en C3 dans les 6 modules ; fixer la liste *-ir* dans le cadre §3 ; lever les ⚠️ contrôlables sur Vèrb'òc/Dicod'òc.
2. Renommer le tableau §3 (« Forme d'apprentissage / Formes également en usage » + pays) et réécrire §2 + Cultura 44.1 sur le francitan.
3. Ajouter au gabarit : (a) pagination en sessions de 10-15 min ; (b) tâche finale en deux voies (privée / communautaire) ; (c) brique « *Los que parlan* » (audio natif) ; (d) brique « *Lo conselh dels vièlhs* » ; (e) titres en langage courant.
4. Décider l'audio : voix humaine obligatoire (Romain + natifs), Votz au mieux en secours pour les corrigés.

### P1 — à intégrer dans la rédaction de la série A1
5. Unité 0 fondue dans A1 + module d'accueil « Tu l'as déjà entendu ».
6. Personnages : un tiers de prénoms/origines de l'Occitanie réelle (Yasmine, Karim, Núria…), nationalités *marroquin/-a, algerian/-a, catalan/-a* en 2.1 ; rééquilibrer les rôles (une vigneronne, un grand-père transmetteur affectif).
7. Encart « *Se parles catalan / castelhan* » (3 lignes de contrastes) dans chaque module A1-A2 ; colonnes CAT/ES dans `lexic.csv`.
8. Contenus terroir : unité ou modules « *La vinha e lo vin* » (A2/B1), chasse-pêche-jardin, dictons du calendrier, prénoms et surnoms.
9. Une chanson **travaillée** (pas seulement citée) par unité A1-A2.

### P2 — avant la mise en ligne
10. Missions réécrites au format DCL réel (5 phases, descripteurs officiels) + une copie d'apprenant corrigée par mission.
11. Dossier « droits » par extrait littéraire (Bodon, Lafont, Roqueta, Delpastre, chansons) ; citations courtes seulement.
12. Bibliographie normée (Sauzet & Ubaud, Sumien 2006, Lafont 1971, OPLO 2020) dans le cadre.
13. Test de positionnement + parcours accéléré romanophone.
14. Un projet C2 « atelier populaire » (séance pour un centre social, évaluée par les participants) à côté des projets académiques.

### Ce que je **ne** propose pas de faire
- **Gamification lourde** (streaks, points, badges) : demandée par Théo et Lina, mais c'est une décision d'interface, pas de contenu ; elle dépend de la techno du site (point encore ouvert). Je note le besoin, je ne l'écris pas dans les modules.
- **Retirer les contenus de luttes** (Marc, Bernard) : ils sont dans l'ADN de Lo Ligam et dans l'histoire des locuteurs ; on équilibre, on ne censure pas.
- **Genre non binaire dans la morphologie** (Inès) : l'occitan n'a pas de forme attestée ; on veille aux rôles et aux prénoms, pas à la grammaire.
- **Parcours « Pro 10 h »** maintenant : pertinent, mais phase 2-3 du projet.
