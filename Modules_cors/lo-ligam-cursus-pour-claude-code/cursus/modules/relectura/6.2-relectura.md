# Module 6.2 · *Quin temps fa ?* : fiche de relecture

Quel temps fait-il ? Dire le temps qu’il fait, aujourd’hui et demain. Générée depuis le site (`app/scripts/fichas-relectura.mjs`) : c’est exactement ce que l’élève lira. Quand tout te va, dis « publie le module 6.2 » : Claude met la date de relecture et le module apparaît.

## Questions pour toi

1. Chanson *Plòu a Marselha* (Lou Dalfin) : la recherche n’a vérifié que le titre, pas les paroles. Tu la gardes ?
2. Le présent pour demain, comme le lexique : *Deman, fa solelh* ; et Lisa au téléphone : *Dimenge, soi al vilatge !* (dimanche, je serai au village). Naturel pour toi ?
3. *Fa solelh*, *Fa vent* (mot à mot : il fait soleil, il fait vent), donnés comme formules toutes faites : c’est bien ton usage ?
4. *freg* : « FRÉTCH », le g final sonne « tch » (lexique). D’accord ?
5. Dans la note culture, *cers* et *autan* restent écrits en français (absents du Basic) : d’accord ?
