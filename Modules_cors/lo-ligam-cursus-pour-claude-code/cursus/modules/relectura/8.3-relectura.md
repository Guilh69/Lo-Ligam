## À retenir (entre dans le carnet) et mots expliqués en passant

| occitan | ça sonne comme | français |
|---|---|---|
| **prene : preni · prenes · pren** | PRÉ-né : PRÉ-ni · PRÉ-nés · PRÉ(N) | prendre : je prends · tu prends · il ou elle prend |
| **Per ieu, …** | pér YÉOU | pour moi, … (pour commander) |
| **un cafè · lo cafè** | un ca-FÈ · lou ca-FÈ | un café · le café (la boisson, et aussi le lieu) |
| **un tè** | un TÈ | un thé |
| **un suc de fruta** | un SUC dé FRU-to | un jus de fruit |
| **l’aiga** | LAÏ-go | l’eau |
| **un veire de…** | un BÉÏ-ré dé | un verre de… (*un veire d’aiga*) |
| **Ai set.** | aï SÉT | j’ai soif. (*set*, la soif, ne se dit pas comme *sèt*, sept) |
| **L’addicion, se vos plai.** | la-di-SYOU, sé bous PLAÏ | l’addition, s’il vous plaît. |

En gras : ce qui entre dans le carnet. Sans gras : expliqué en passant (glossaire, carte).
