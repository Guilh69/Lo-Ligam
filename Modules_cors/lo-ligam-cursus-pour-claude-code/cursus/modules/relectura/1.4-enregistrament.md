# Module 1.4 · *E tu ?* : liste d’enregistrement

6 phrases, environ 3 minutes. Enregistre d’une traite sur ton téléphone, dans un endroit calme : lis chaque phrase une fois, naturellement, et laisse **deux secondes de silence** entre deux phrases (c’est ce silence qui permet de découper). Si tu te trompes, redis la phrase : la dernière prise compte.


**scène « Karim »**

1. Adieu !
2. Me dison Karim.
3. Soi de Besièrs.
4. Mas demòri a Tolosa.
5. E tu, cossí te dison ? D’ont siás ?
6. Encantat ! A lèu !

Envoie le fichier tel quel : Claude le découpe, l’allège et le range dans `app/static/audio/moduls/1-4/`.
