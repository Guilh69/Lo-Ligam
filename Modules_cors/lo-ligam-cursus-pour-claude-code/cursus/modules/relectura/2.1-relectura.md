# Module 2.1 · *Siás occitana ?* : fiche de relecture

Es-tu occitane ? Dire sa nationalité et celle des autres. Générée depuis le site (`app/scripts/fichas-relectura.mjs`) : c’est exactement ce que l’élève lira. Quand tout te va, dis « publie le module 2.1 » : Claude met la date de relecture et le module apparaît.
