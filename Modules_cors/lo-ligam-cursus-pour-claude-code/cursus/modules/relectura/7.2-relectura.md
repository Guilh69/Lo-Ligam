## À retenir (entre dans le carnet) et mots expliqués en passant

| occitan | ça sonne comme | français |
|---|---|---|
| lo lièch | lou LYÈTCH | le lit (tu l’as dit en 6.3 : *Vau al lièch*) |
| **sus · sul · suls** | SUS · SUL · SULS | sur · sur le · sur les (*sul* = *sus* + *lo* ; *suls* = *sus* + *los*) |
| **jos** | DJOUS | sous |
| **davant** | da-BAN | devant |
| **darrièr** | da-RRYÈ | derrière |
| **al · del · als · dels** | AL · DÉL · ALS · DÉLS | au · du · aux · des (*al* = a + *lo* ; *del* = *de* + *lo*) |
| **al costat de…** | al cous-TAT dé | à côté de… |
| **entre** | ÉN-tré | entre |

En gras : ce qui entre dans le carnet. Sans gras : expliqué en passant (glossaire, carte).
